  ## PWA 알림
  - push_subscription 에 유저ID, 브라우저정보(endpoint), 웹푸시에 필요한 기타 정보를 로그인 시 등록한다.
  - 알림은 등록된 브라우저에게 보낸다.
    - 유저가 오프라인 OR 온라인 + 다른 방에 있을 경우만 알림을 보낸다.
  - push_subscription 에는 브라우저에 마지막으로 로그인된 유저에게 알림이 간다.(로그아웃되어도 알림은 간다. 다만 다른 계정으로 마지막으로 로그인하면 이전에 로그인을 했고 알림 수락을 해도 알림이 가지 않는다. 해당 브라우저에 알림이 받도록 등록된 것은 마지막으로 로그인된 유저이기 때문이다.)
